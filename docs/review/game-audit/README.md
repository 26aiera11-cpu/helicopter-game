# 전체 기능 자동 점검

2026-11-01(KST) · 기준 `f14abc5` · `feature/selection-screen-integration`

기존에는 선택화면 8개·게임 회귀 15개·오프라인 단일 HTML 12개 검사 그룹의 개별 보고서가 있었다. 무기·아이템·충돌·전체 단계 전환을 통합한 보고서는 없어 이번에 보완했다. 게임 코드·이미지·사운드는 수정하지 않았다.

## 결과

**추가 자동 검사 11개 그룹 통과. 게임 진행을 막는 문제는 발견하지 못했다.**

| 기능 | 확인 내용 |
| --- | --- |
| 캐릭터·강화 | 세 캐릭터 × 강화 0~5의 발사 수·피해량·속도·관통·유도탄 구성 |
| 연속 발사 | 실제 update 루프에서 캐릭터별 연사 순서와 첫 강화의 연사 증가 |
| 탄환·충돌 | 탱코 관통, 강화 폭에 따른 판정, 빙글 유도 방향 전환 |
| 보스 공격 | 지역별 1/3/3/5발 패턴 및 단계별 탄속 |
| 아이템·효과 | 체력 +2와 최대치, 강화 최대 5, 특수 적의 아이템·점수·파티클 |
| 피격·종료 | 적 탄환·몸체 충돌, 무적 시간, 체력 0에서 게임 오버·결과 표시 |
| 단계 전체 | 경고→적 생성→실제 충돌로 처치→자동 단계 전환을 20개 웨이브 수행, 보스 4종 처치, 최종 점수 160과 클리어 복귀 |
| 재시작 | 단계·점수·체력·무기 초기화 |
| 센서 계산 | 합성 입력으로 중립점·정규화·중앙 보정 확인 |
| 오류 | 잡히지 않은 JavaScript 오류 없음 |

기존의 [선택 강조](../selection-highlight/README.md), [선택·게임 회귀](../selection-final/README.md), [단일 HTML 오프라인·실제 터치 입력](../galaxy-test/README.md) 보고서도 함께 대조했다. 해당 검사 결과를 이번에 전부 다시 실행했다고 기록하지 않는다.

## 발견 사항

| ID | 문제 | 판단 |
| --- | --- | --- |
| N1 | 게임 오버 경로가 음악을 일시정지하지 않고 `gameAudioStarted`도 유지 | 기존 문제. 메뉴·재시작 가능, 진행 차단 없음 |
| N2 | 보스 보상이 생성된 직후 단계 전환에서 제거됨 | 기존 문제. 다음 지역 진입 가능, 진행 차단 없음 |

이번에는 위 문제와 플레이 중 트리오 외형을 수정하지 않았다. 이미지 로더 경쟁 가능성·세로 안내 중 진행 등 기존 정적 분석 사항도 개발 로그에 유지했다.
