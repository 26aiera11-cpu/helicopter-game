## 적용 범위와 시험 수치

지역 ID7 / `world-2:machine-fortress`의 일반 적만 새로운 세 모듈 `config.js`, `spawns.js`, `combat.js`를 사용한다. 아래 수치는 Issue의 **Galaxy 사용자 피드백 전 1차 시험값**이며 최종 밸런스 승인이 아니다.

생성되는 개체에 변경 불가능한 `machineSpeciesId`를 한 번 부여하고 그래픽/HP/AI가 이 ID를 공유한다. 기존 `kind` 값이 이후 변경돼도 다른 종으로 표시되지 않으며 재준비가 체력을 회복하거나 종류를 다시 뽑지 않는다. 기계 요새 전용 xorshift32 RNG를 사용한다. 같은 시드는 같은 선택 결과를 만들며 기존 `Math.random`, 설원·화산·폭풍 전용 RNG의 상태나 소비 순서를 바꾸지 않는다.

기존 단계당 6처치 목표를 유지한다. 정상 5단계는 혼합 일반 적 6처치 후 기가코어가 등장하며, 개발자 직접 5단계는 즉시 보스다. 일반 처치100점·아이템 몬스터200점·보스2000점 및 보상/순위/분석 저장 규칙을 유지한다.

## 경고·판정·수명

돌진 경고는 실제로 진행할 수 있는 짧은 직선 경로와 기존 몸체 반경16px의 폭을 표시한다. 화면 경계에서는 경로를 잘라 미끄러지거나 방향을 바꾸지 않는다. 드론은 동일한 선분을 경고·그리기·충돌에 사용하고 끝이 둥근 폭7px 선으로 그린다. 실제 플레이어 판정은 기존 적 탄환/빔과 같은 반경12px를 합산한다. 반경0 탐침과 독립 Python 선분 거리 계산으로 레이저 외형과 판정의 경계를 검사했다.

공격 상태는 게임 `dt`만 사용하며 공격용 `setTimeout`이 없다. 1/300초 분할 적분으로 60/120/300Hz를 비교했고 단일 폭주 `dt`는 .25초까지 반영한다. 새 포탄은 생성 프레임의 남은 시간만 이동해 프레임 분할에 따른 위치/수명 차이를 막는다. 숨김 탭과 내부 나가기 확인창에서는 기계 요새 진행을 멈춘다. 사망·단계 변경·보스 시작·나가기·재시작은 상태와 전용 빔/탄환을 정리한다. 적 사망 시 그 적이 소유한 포탄도 제거한다. 화면 크기가 바뀌면 위험 효과를 취소하고 1.2초 안전 휴식에 들어가며 체력을 회복하지 않는다.

전용 일반 포탄은 전체24개/개체당2개 이하, 빔은 개체당1개로 제한한다. 상한에 걸려도 기존 기본 발사로 우회하거나 매 프레임 재발사하지 않는다. 효과는 Canvas에만 그리므로 HUD/조이스틱/발사/나가기 버튼을 덮는 DOM 입력 영역을 만들지 않는다.

## 기존 자산·게임 보호

[보존 검사](preservation.json)는 index의 정확한18연결 차분, 그래픽 모듈의 ID/상태 안내2차분, 월드 안내2차분만 역변환하면 기준의 전체 index와125기존 자산이 일치함을 확인한다. 기존125자산 중123개는 파일 바이트 자체가 같으며 두 변경 자산도 허용한 문구/ID 연결 이외에는 같다. 신규3모듈은 별도 SHA256으로 고정했다. 과거 보호 해시를 새 이미지로 덮어쓰지 않았다.

- 일반 이미지 기본 너비40px, 보스132px, 원본 비율·알파·중심/애니메이션·배경 contain을 유지한다. PNG11개, 원본 manifest, 효과 PNG, 플레이어/다른 지역 이미지와 모든 음원 바이트는 그대로다.
- **표시40px와 실제 충돌 반경16px(지름32px)의 차이를 유지**한다. 기존 x17/y18 중심 제한에서 기본40px 이미지가 왼쪽으로 약3px 잘릴 수 있는 기존 한계도 남아 있다. 모든 종의 네 모서리10초 이동 검사로 기존 제한을 넘지 않는지 확인했다. 충돌을 임의 확대하거나 외형을 다시 저장하지 않았다.
- 기존 렌더러의32/40px 전후 검사를 새로 허용된17개 단계/종 조합으로 갱신했다. 3캐릭터·5시각상태·4화면/DPR·전후의 **2,040개 Canvas 측정**에서 양축1.25배·전체 소스 사각형·피벗·비율·보스132px를 계속 검사한다. 이번에32px로 되돌리는 기능은 없다.
- 월드1 기본20단계/확장40단계, 기존 설원·화산·폭풍 전투, 플레이어/무기/조작/센서/점수/아이템/저장/오디오 모듈을 변경하지 않는다. 기계 요새 음악은 기존 `musicProfile:0` 숲 임시 음악이다.

## 독립 HTML·ZIP

[HTML](../../../dist/heli_trio_galaxy_test.html)은 **76,795,469바이트**, SHA256 `4e404c48d78d613703b5d5e267b1885f418d732a7f0a71f6d66edf585bc53321`이다. ZIP은 **56,141,178바이트(약53.54MiB)**, SHA256 `175c35b15d1a4cf47ae57521cfbbd0a8a61b00f52bb097990fc0464b2af13eb2`다. ZIP에는 최신 HTML 한 개만 있다.

- [갤럭시 ZIP 다운로드](https://raw.githubusercontent.com/26aiera11-cpu/helicopter-game/refs/heads/feature/machine-fortress-normal-combat/dist/heli_trio_galaxy_test.zip)
- [빌드 결과](build.json) · [패키지 CRC/크기](package.json) · [별도 압축해제/내장 바이트 검사](embedded-verification.json)

새3모듈 포함26스크립트·CSS·PNG11개·모든 기존 외부 음원5파일·기존 나머지 내장 자산을 포함한다. 손상 없는 폭풍 하늘 배경 SHA `96a86d2d0fd191d2b48904dc1a15f4a848d1937e044dc2b23900aaa6ad69817d`도 유지한다. 별도 디렉터리 압축해제 후 전체 HTML 바이트 일치/ZIP CRC/내장 원본 바이트를 검사했다. 네트워크를 끈 브라우저에서 동일 HTML로 외부 요청0을 확인했다. 관리 환경의 file:// 탐색 제한을 우회하지 않고 빈 origin에 실제 HTML을 주입한 오프라인 검사이며, 실제 Galaxy 로컬 파일 연결은 추가 확인이 필요하다.

보고서 JSON의 대용량 `data:` URI는 공개 사본에서 MIME/길이/SHA256 설명으로 치환할 수 있다. 수치·상태·실패는 삭제하지 않으며 원본/게시 사본 해시는 `artifact-manifest.json`에 기록한다. 실제 게임 자산과 dist는 이 과정에서 바꾸지 않는다.
