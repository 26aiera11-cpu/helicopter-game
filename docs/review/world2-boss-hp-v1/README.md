## 필수 검증과 실행 범위

최종3개 모음·19그룹 통과, 최종 실패0개. 일반 집중검사6그룹/6.42초, 오프라인 집중검사5그룹/31.69초, 기존 boss_reward8그룹을 실행했다. 이 시간은 비교 전투의 시뮬레이션 초와 구분되는 브라우저 검사 구간의 실제 경과이며, 기존 보상 모음의 경과시간은 따로 계측하지 않았다. 최초6.33초 시도는 아래 실패 이력에 보존했다.

실제 스폰8지역×3캐릭터×0/3/5강=72건에서 체력과 강화 후 재계산되지 않는 스냅샷을 확인했다. 지역별 두 보상8경로는 실제 발사/접촉을 통제하여 점수2000/중복방지, 보상 후 지역 회복+2 순서, 아이템 객체·남은 수명, 다음 지역/최종클리어 및 결과1회 저장을 확인했다. 이 QA의 투사체 접촉/난수 통제는 위24전투의 난이도 측정과 별개다. 개발자5단계 즉시100HP 보스와3초 게임오버 복귀·기록 무저장,568×320 화면도 확인했다.

기존 W2 검사15파일의 직접HP 기대값과 그에 의존하는 처치 반복 상한만 정확히 갱신했다. [허용 차분](test-expectation-deltas.json)을 역변환하면 기준 파일과 같고 Python AST 및 assert 수가 유지된다. 이15개 역사적 모음의 브라우저 전수 실행은 하지 않았다. 세계40단계 재분석·등록86개 전체 회귀·대규모 화면 캡처·다른 수치 실험도 생략했다. 필요한 검사만 수행한 결과이며 전체86모음 통과로 표시하지 않는다.
