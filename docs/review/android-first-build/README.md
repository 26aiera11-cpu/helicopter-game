휴대폰에서 APK를 받아 파일 앱으로 열어 설치한다. 출처 설치 허용이 필요하면 해당 파일 앱의 권한을 확인한다. AAB는 이번에 만들지 않았고 서명 전/후 생성 절차만 문서화했다. Debug APK는 출시용 서명 결과가 아니다. 테스트키는 저장소 밖에 보관했으며 키/비밀번호/개인 SDK 경로는 커밋하지 않았다.

## 기존 작업을 보존한 재개

사용 한도로 중단된 후 작업 복사본·JDK21/SDK36/Gradle 캐시·기존 APK가 모두 남아 있음을 확인했다. 검사보다 먼저 체크포인트 **192c87106098e81eb74246ab0dce004005273d4a**를 커밋·푸시했다. [checkpoint.json](checkpoint.json)은 이때의 미완료 상태와 첫 APK의 해시를 기록한 **역사적 체크포인트**다.

이 재개에서는 JDK·SDK를 재설치하거나 첫123태스크 빌드를 반복하지 않았다. APK의 호환 계층이 최신 소스와 달라 캐시를 쓰는 오프라인 증분 패키징만 수행했다. 센서 신호 판정 보완 전후 각각11초/21실행·69재사용이다. 마지막 APK 안의220개 웹 파일은 현재 webDir 파일과 전부 바이트가 일치한다.

## 최소 구현과 원본 보호

Capacitor8.6.0/App8.1.2 Android 프로젝트, 가로 고정, 시스템바 숨김/스와이프 일시 표시, 노치 안전영역에 맞춘 네이티브 콘텐츠 프레임을 추가했다. 기존 승인된 선택화면 뾰코 PNG를 파일 변경 없이 아이콘/스플래시에 재사용한다.

원본 index.html과131개 자산은 기준과 바이트가 같다. 월드2 HP72/80/90/100,40단계·무기/캐릭터/점수/아이템/사운드·기존조작은 재작성하지 않았다. 원본 HTML의83개 data URL을 바이트 그대로 분리해 앱 HTML은18,765,613바이트에서210,055바이트로 줄였다. 이미지·음원의 압축/샘플링/픽셀 변경은 없다. APK의73MiB 수준 크기는 실제 산출물 수치이며 실기기 로딩 속도 개선을 측정한 결과는 아니다.80MB 단일HTML을 복제하지 않고 작은HTML+로컬자산으로 로드한다.

게임 프레임 전체의 Android 전용 일시정지 게이트로 이동·탄환·음악을 멈추고, 복귀 후 계속 플레이를 누르면 입력을 초기화해 재개한다. 뒤로 가기는 기존 나가기/취소·도움말/순위표 닫기와 연결되며 선택화면에서는 내부 앱 종료 확인창을 사용한다. confirm/alert나 오디오 보안 설정 해제는 추가하지 않았다.

센서는 기존 웹 이벤트를 우선한다. 신호가 없을 때만 사용자 센서 버튼 이후 Android Gravity/Accelerometer를50Hz로 읽어 기존 중력 입력의×3·÷17 계산에 전달한다. 네이티브 표시 회전각을 원래 screenAngle 계산 경로에 공급하며 게임 속도·가속·감쇠·회전 감도 수치는 유지한다. 신호 판정은 실제 게임처럼 두 축이 모두 유효하고 센서가 켜진 이후인 경우만 인정하며, 원래 비동기 권한 처리 완료 후 대체 입력을 시도한다. 센서 사용 불가 시 드래그 안내와 기존 보조 이동을 유지한다. 실제 갤럭시 방향/감도/권한·보정은 사용자 확인이 필요하다.

## 발견한 검사·호환성 문제

초기 생성기에서 원본의 중복 닫기태그에 앱 코드를 두 번 넣던 문제는 마지막 닫기태그에1회 삽입하도록 보완했다. 중단 전 JDK 경로·SDK 메타데이터/라이선스 문제는 이미 해결돼 이번에는 다시 설정하지 않았다.

재개 후 DOM 오디오 태그만 세던 검사에서 원래 `new Audio()`로 만든 월드1 음악 객체를 누락했다. 게임 오버 후 선택화면 음악을 기다려 입력 대상이 선택화면이 된 원인을 추적으로 확인했다. Audio 생성 객체와 DOM 태그를 함께 추적하고, 입력 QA에는 적 생성을 중단해 전투 간섭을 제거했다. 이것은 전투 생존/밸런스 검증이 아니다. 음악 버튼도 실제 선택화면의 버튼을 거쳐 설정하도록 검사 흐름을 정리했다.

센서 판정에서는 활성화 전/불완전 신호가 대체 입력을 막을 수 있어 앱 호환 계층에서 유효한 두 축·활성화 이후 신호만 인정하고 원래 권한 처리 Promise 완료를 기다리도록 보완했다. 원래 게임의 센서 계산은 바꾸지 않았다. 이전 실패/부분 통과 로그를 보존하고 부분 그룹을 최종8에 중복 합산하지 않았다. APK 메타데이터 검사는 새 aapt2의 minSdkVersion 표기 형식에 맞춰 읽었다.

## 미실행·기기 확인

기기/에뮬레이터 실행, 진짜 센서 부호·감도·지연, 하드웨어 뒤로 가기/노치/시스템바, 실제 스피커·오디오 포커스, 비행기 모드 첫 설치와 장시간 전투·열/메모리는 **미검증**이다. Windows/AAB 빌드도 실제 실행하지 않았다.40단계 밸런스 재분석/기존 전체 Python 회귀/대규모 캡처는 하지 않았다.

앱의 localStorage는 WebView의 별도 저장소다. 기존 브라우저 기록을 가져오거나 삭제하지 않는다. 같은 앱 ID·서명으로 덮어쓰면 앱 데이터를 유지할 수 있으나 삭제/데이터 초기화는 순위표를 지운다. 정식 서명·스토어 업로드는 별도 승인 후 진행한다.
