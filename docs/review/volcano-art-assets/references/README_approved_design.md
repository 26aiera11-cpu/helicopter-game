# 헬리 트리오 – 월드2 화산 지역 승인 시안 전달팩

이 ZIP은 **게임용 분리 PNG가 아닌 디자인 참조 이미지** 3장을 포함합니다. 원본 합성판을 그대로 게임 화면·스프라이트로 쓰지 마세요.

## 사용자 승인 사항
- 월드2 두 번째 지역: **화산(신비로운 화산지대 B안)**. 위에서 수직으로 내려다보는 탑다운 시점, 검붉은 바위/빛나는 용암, 전투 구역 중앙은 읽기 쉽게.
- 01: 최종적으로 선택한 배경 및 일반 몬스터 탑다운 콘셉트. 일반 몬스터 모두 **프로펠러 제거**.
- 02: 일반 몬스터 4종의 **첫 번째 애니메이션 시안 선택**. 몬스터: 불씨콩, 용암 도마뱀, 화산 박쥐, 마그마 갑충. 설원과 시각 품질은 유사, 효과 과다하지 않게. 대기 기본 이미지, 이동 4, 피격 2, 소멸 4, 공격 시 기존 탄환/짧은 동작 사용; 이 수치는 콘셉트 기준이며 실제 자연스러움을 보며 최소 변경.
- 03: 보스 마그마 드래곤, 탑다운, **날개는 기존보다 위쪽 방향으로 펼쳐진 최종 수정안**, 크기 유지. 대기 4, 이동 6, 공격 4, 피격 3, 소멸 4 수준의 시안. 기존 설원 보스와 균형 맞출 것.
- 화산 공격 콘셉트: 불씨콩 화염, 도마뱀 측면 이동, 박쥐 불규칙 이동, 갑충 방어형; 보스는 화염구 연사/용암 분출/회전 화염. **전투 수치 미확정**.

## 구현용 자산 제작 시
- 1920x864 가로형 **배경 이미지만** 별도 파일로 제작. 글씨/패널/몬스터/UI/보스/탄환이 배경에 포함되지 않아야 함. 승인 콘셉트와 조화 유지.
- 일반 몬스터 4종 + 보스 1종 각각 **독립 투명 PNG**와 상태별 투명 애니메이션 아틀라스를 생성. 글씨/배경/테두리 패널 제외, 주변 여백, 프레임 위치·셀 크기·시간을 매니페스트에 명시. 적끼리 외형 섞이지 않도록.
- 컴포지트 원본은 반드시 참조로 보존. 프레임을 원본 디자인과 동떨어지게 임의로 재창작하지 않음.
- 월드1, 설원, 뾰코 이름/제목을 그대로 유지. 난이도 수치는 월드2 전체 완성 뒤 재조정 예정.
- 원본 이미지가 불투명한 합성 시트인 경우 자동 잘라내기만으로 완전한 투명 아틀라스가 되지 않음. 자산 품질을 별도 검증할 것.
