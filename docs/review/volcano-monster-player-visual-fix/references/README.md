# 헬리 트리오 화산 2종 수정 기준 이미지

01: 사용자가 "맘에 들어. 이대로 수정하자"라고 최종 승인한 용암 도마뱀+마그마 드래곤 수정 디자인 시트. 용암 도마뱀은 가늘고 뿔이 없는 도마뱀 머리, 명확한 네 발, 길고 보이는 꼬리. 마그마 드래곤은 넓게 펼친 양쪽 날개, 상대적으로 작은 머리, 선명한 긴 꼬리. 아래쪽을 향한 얼굴과 위에서 내려다보는 시점을 지킬 것.
02: 사용자가 직접 첨부한 마그마 드래곤 기준 이미지. 최종 디자인 01과 충돌하는 디테일이 있으면 01의 승인된 외형을 따르되 원형·날개 펼침은 02를 존중.

주의: 이미지들은 배경과 레이블이 포함된 참고 시안으로, 게임용 투명 PNG/완성 아틀라스가 아닙니다. 기존 'assets/volcano'의 2종 원화와 애니메이션 아틀라스만 교체해야 하며, 나머지 몬스터/배경은 그대로 두세요. 아틀라스 좌표·피벗·시트 크기가 바뀌면 manifest도 함께 고쳐야 합니다. 기존 상태 수(일반12, 보스21)를 지켜주세요.

캐릭터 뾰코/빙글/탱코 외형 이슈는 이미지 참조 ZIP과 별개로: 월드1 게임 플레이 중 쓰이는 정확한 각 캐릭터 스프라이트 및 크기/방향/회전을 월드2 설원·화산에서도 동일하게 유지해야 합니다. 기존 월드1 PNG를 수정/복제하지 말고 원본 소스를 공통 참조하도록 원인부터 조사하세요. 선택화면 그래픽과 혼동하지 마세요.
