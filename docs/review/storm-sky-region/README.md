작업 브랜치: `feature/storm-sky-region` · 기준: `c2d03f8306557c72be7f61666198919c2412b2ae` · 작업일: 2026-11-06 KST

[Issue #26](https://github.com/26aiera11-cpu/helicopter-game/issues/26)의 전체 요구사항과 기존 개발 기록을 확인했다. 시작 당시 원격 main/지정 작업 브랜치는 같은 커밋이었다. main에는 커밋·병합·배포하지 않는다. `HELI_TRIO_SPEC.md`는 없어 이번 확정 규칙과 Issue #26을 적용했다.

## 구현 범위

- 지역 ID0–5를 보존하고 ID6 `world-2:storm-sky`를 추가했다. 월드 2는 **설원→화산→폭풍 하늘** 순서다. 기본 월드 1의20단계는 유지하고, 기본OFF인 월드2 시험 경로만35단계로 확장했다.
- 게임 방법의 개발자 지역 바로 시작 목록은 registry에서 자동 생성된다. 폭풍 하늘1–5단계와 세 캐릭터를 지원한다. 직접5단계는 즉시 보스이며 선택 지역 보스를 처치하면 종료하고 기록을 저장하지 않는다.
- 정상 경로는 다른 지역과 같이 각 단계6킬 규칙을 유지한다. 일반1–4단계 이후5단계에서도6킬 뒤 보스가 등장한다. 일반 단계 보너스500/일반 처치100/아이템몹200/보스2000은 그대로다. 무아이템 전체 점수는 기본28,000, 시험49,000이다. 아이템몹21마리를 포함한 시험 경로는53,200점이다.
- 기존 순위/분석 저장 키·버전1·캐릭터ID·지역ID를 유지한다. 기존 월드2 기록은 그대로 읽고 새 결과의 지역 레이블만 폭풍 하늘로 표시한다. 일반 순위와 시험 순위는 기존처럼 별도다.

## 승인 이미지와 애니메이션

[원본 패키지/CRC/파일별SHA-256](source-package.json)에 전달된 ZIP8파일(디렉터리 포함9항목)을 기록했다. 배경1920×864 한 장과 네 일반 몬스터512×512 PNG는 바이트 그대로 사용하며 다섯 단계 모두 같은 배경이다. 다른 지역 그래픽과 플레이어 이미지는 변경하지 않았다.

보스 자료는 게임용 투명 PNG가 아닌 설명판이었다. 설명판 두 장은 `assets/storm_sky/references/`에 보존하고, 승인된 보스만 imagegen으로 투명 분리했다. 푸른 구름·금색 번개 장식과 고리·양쪽 터빈·흰 수염·회오리 꼬리를 유지했다. 문구·패널·공격 도식은 스프라이트에 포함하지 않았다.

아틀라스는 원본 PNG를 그대로 사용하는 비손실 단일 셀 방식이다. 매니페스트에 각 프레임의 원본 사각형·피벗·변환을 명시하고,5상태×16키프레임×5종=80개를 사용한다. 대기/이동/공격/피격/소멸은 확대·기울기·알파 기반이며80장의 새로 그린 포즈라고 보고하지 않는다. 원본 비율과 투명도를 유지한다. `assets/storm_sky/prepare_assets.py`로 승인 ZIP과 분리된 보스 PNG에서 매니페스트/원본 셀을 재현할 수 있다.

## 폭풍의 지배자

기본HP20과 기존 강화 보정 `[1,1.1,1.4,1.6,1.9,2.2]`, 충돌·피격 무적·2000점·50:50 자동 회복/강화 보상을 재사용한다. 세 일반 패턴은 같은 패턴이 연속되지 않도록 무작위로 고르며, 네 번째 각성은HP50%에서 한 번만 발생한다. 각성까지 무작위로 지연시키지 않는다.

1. **번개 탄막:**0.8초 경고→8방향45° 간격→0.45초 뒤22.5° 어긋난8방향. 탄속82px/s·수명4초·동시32개 상한.
2. **회오리 소환:**0.8초 경고→2–3개, 반경20px·34px/s·수명5초, 불규칙 이동. 접촉하면HP/점수를 건드리지 않고 화면 안 안전 위치로 옮긴다. 반경22px 여유로 보스·일반 적·적탄·회오리·레이저·실제 UI를 피하며 공간이 없으면 이동을 생략한다.1.4초 접촉 쿨다운·0.75초 보호·0.65초 표시용 두 바퀴 회전과 바람 흔적을 사용한다. 플레이어 조준값과 입력 소유자는 유지한다.
3. **전기 레이저:**양쪽 터빈1초 예고→2초 분사·초당15° 회전. 길이는 `clamp(H×.53,120,185)`이고 폭10px다. 몸체의 실제 애니메이션 변환을 터빈 앵커에도 적용한다. 표시와 피해가 같은 선분을 사용하며 기존 플레이어 반경/1.55초 무적을 적용한다. UI 영역은 표시·피해에서 함께 제외한다.
4. **폭풍 소용돌이/2페이즈:**HP50% 이하에서 한 번만2초 각성,22px/s 끌어당김 후12방향 탄막. 기존 탱코 가속·드래그 입력으로 저항 가능하다. 공격률×1.2(시간÷1.2), 탄속×1.1이며 공격 사이 휴식은 최소1.5초다. 일반 휴식1.9초→2페이즈1.58333초다.

모든 공격은 게임 dt로 진행한다. 숨김/종료창에서 멈추고 크기 변경 시 현재 위험 효과를 취소해 새 UI 범위의 휴식으로 전환한다. 사망·처치·나가기·재시작 시 정리하며 비동기 공격 타이머를 추가하지 않았다. 보스 처치 소멸 애니메이션 후 다음 지역/기존 결과 화면으로 진행한다.

## 음악과 보호

폭풍 하늘 전용 BGM은 **후속 작업**이다. registry의 음악 프로필0으로 기존 숲 일반/보스 곡을 명시적으로 임시 사용하고 화면에도 ‘BGM 숲 임시’를 표시한다. 선택곡·화산 두 곡·기존12WAV/SFX·ON/OFF·미디어 단일 재생 owner는 변경하지 않았다.

기존92개 자산 중 registry의9개 허용 차분을 되돌리면 전부 기준 바이트와 같다. index의32개 통합 차분을 되돌리면 기준 전체와 같다. 플레이어·무기/탱코 밸런스·자이로/조이스틱/터치·설원 전투/115프레임·화산 혼합/일반 전투/69프레임·승인된 아래 선분사0.2초 후3.8초360° 브레스·기존 음악·점수/저장·아이템·3초 게임오버·전체화면/내부 종료창은 보호했다.

## 검증과 캡처

최종 **61개 모음 중60개 통과·1개 미해결 실패, 완료 그룹769개**다. 폭풍 하늘 일반/오프라인 각19그룹과 경계6그룹은 모두 통과했다. 실패 모음의 부분16개는 통과 합계에 넣지 않았다.

## 남은 확인과 미해결

- 기존의 **긴 멀티터치 후 설원5단계 나가기 click 누락**이 이번 오프라인 worlds 검사에서도 재현됐다. [이번 실패](regression/worlds-offline/run.log)와 진단 JSON/화면을 보존한다. 일반 worlds의35단계 검사는 통과했지만 기존 간헐 문제가 해결됐다고 주장하지 않는다. 이번 작업에서 controls.js를 수정하지 않았다. [기존 실패 기록](../volcano-bgm/README.md)도 그대로다.
- 실제 Galaxy Samsung Internet/Chrome의 파일 연결·다운로드/압축 해제, 센서 권한·진짜 기울임/멀티터치·장시간 성능/발열, 스피커 청취, 체감 난이도는 미검증이다.
- 직접 file://가 환경 정책으로 거부되면 정책을 우회하지 않고 동일 독립HTML을 빈 origin에서 네트워크 차단해 검사했다. 실제 휴대폰 로컬 파일 열기는 별도 확인이 필요하다.
- 전용 폭풍 BGM과 새로 그린 다중 포즈 애니메이션은 포함하지 않았다. 원본 셀/매니페스트 변환 애니메이션과 명시된 임시 음악을 사용한다.
