# 탱코 연사20% 감소 전후 비교

기준f622f3f 실제 HTML과 새 HTML을 Chromium에 각각 로드했다. 제품 변경은 탱코 발사 간격×1.25 한 곳이다. 거리160px, 정지, 매 틱 중앙 조준, 기존 등장 전환1.5초/최초 쿨다운0을 포함한다. 실제 갤럭시 성능이나 사람의 조준 시험이 아니다.

발사 횟수는 shoot() 동작 수다. 0/1강은1발,3/5강은2발을 생성하므로 생성 탄환 수도 기록한다. 적 도달은 피격 무적 중이라도 실제 적 탄환/플레이어 충돌을 센다. 통과는 차단/도달 없이 화면 밖 또는 수명 종료로 제거된 탄이고12초 끝에 비행 중인 탄은 별도다. 적 발사=차단+도달+통과+비행 중이 모든 행에서 성립한다.

12초 방어 검사에서만 보스 HP1,000,000을 사용했다. 플레이어는 실제9HP와 기본 피격 무적을 유지하고12초 생존했다. 처치 시간은 정상 보스 HP와 무적 플레이어로 별도 측정했다. 적 발사 시각/위치/속도/반경/수명 배열의 일치를 검사하고 해시를 보관했다.
