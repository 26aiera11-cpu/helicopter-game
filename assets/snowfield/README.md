# 헬리 트리오 — 월드 2 설원 그래픽 v2 (승인 조합)

## 구성
- **배경**: 첫 번째 설원 시안 그대로 사용. `background/snowfield_1920x864.png` 파일은 기존 승인본과 바이트 단위 동일. 1280×576 축소판 포함.
- **적 몬스터**: 최신 승인된 **헬기가 아닌 귀여운 몬스터** 5종. 개별 투명 PNG가 `monsters/` 폴더에 있음.
- **애니메이션**: 각 몬스터당 `animations/{id}_atlas.png`와 개별 프레임 PNG. 5개 상태(대기 4·이동 6·공격 4·피격 3·소멸 6), 총 **23프레임×5종=115프레임**.
- `asset_manifest.json`: 상태/행/프레임/좌표/시간 정보.
- `preview/`: 원본 배경의 몬스터 배치 JPG, 투명 분리 확인 이미지, 간이 GIF.
- `source/`: 승인한 배경 및 몬스터 원본 시안 보관.

## 중요 안내
**이번 애니메이션은 프로토타입**입니다. 기존 승인 원화를 보존한 상태에서 바운스·흔들림·공격 이펙트·피격 플래시·파티클 소멸 등을 투명 프레임에 합성했습니다. 방향별로 다시 그린 그림이나 별도 포즈의 수작업 동작을 생성한 것은 아닙니다.

아틀라스는 몬스터마다 6열×5행이며, 행 순서는 `idle, move, attack, hit, defeat`입니다. 각 행의 실제 프레임 수는 매니페스트에 기록했습니다. 캐릭터 중심 정렬 셀을 사용하므로 기존 게임의 좌표/히트박스/실제 표시 크기는 별도 코드 통합 단계에서 조정해야 합니다.

설원 배경은 **무한 반복용 seamless 타일이 아니며**, 타일 이음새는 별도 작업이 필요합니다. 몬스터 크기·HP·탄속·공격 패턴은 아직 게임 코드에 적용하지 않았습니다. Codex가 작업 중인 월드 관리 로직과 충돌하지 않도록 **GitHub 게임 소스는 수정하지 않았습니다.**
