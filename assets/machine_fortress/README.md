# 모바일 경량 ZIP 안내

이 ZIP은 원본 ZIP에서 references/의 4개 참고 이미지(게임 실행에 불필요)를 제외한 경량판입니다. 배경 1개, 몬스터 4종, 보스 2종, 효과 4종 총 11개 PNG와 asset_manifest.json은 원본과 바이트 단위로 동일합니다. 따라서 그래픽 통합용으로 사용할 수 있습니다.

# 헬리트리오 기계 요새 — 그래픽 리소스 v1 (디자인 검토용)

- 이 ZIP은 **게임 적용 전 개별 이미지 자산 묶음**입니다. Codex/GitHub에 아직 통합되지 않았습니다.
- 배경은 사용자가 확정한 **탑다운 금색 톱니 문양 버전**을 원본 해상도 그대로 보존했습니다. 비율을 임의로 늘리거나 자르지 마세요.
- 적 4종: `enemies/screw_bot.png` (나사봇), `gear_wasp.png` (톱니벌), `laser_drone.png` (레이저 드론), `armored_turret.png` (장갑 포탑).
- 보스 2종: `boss/giga_core_normal.png` (일반), `giga_core_overdrive.png` (HP 50% 이하 폭주).
- 공격 효과: `electromagnetic_wall.png` (밝은 파랑), `electromagnetic_warning.png` (위험 예고), `*_dim/motion` 대체 시안. 모두 투명 PNG.
- 전자기 장벽은 코드에서 **화면 높이의 75%**로 표시하고 좌→우 또는 우→좌로 움직입니다. 위/아래 중 한곳의 **25% 회피 공간**은 아무것도 그리지 않고 기존 배경만 표시합니다. 2×2 랜덤 4패턴.
- 모든 이미지는 제공된 확정 콘셉트를 참조해 제작된 1차 분리 이미지입니다. 크기·투명 가장자리·화질은 실제 갤럭시에서 검수한 후 확정하세요.
- `references/`에는 원본 콘셉트와 재분리 가능한 원본 스프라이트 시트를 보관했습니다. **그림 안의 라벨·설명·프레임 장식은 게임용 스프라이트에 포함하지 않았습니다.**
- 애니메이션은 아직 제공하지 않습니다. 최종 렌더링 크기, 정확한 피격 판정, 각 적 고유 동작은 게임 구현 시 별도 검증이 필요합니다.
- 이 파일을 추가하는 작업에서도 현재 main의 정상 동작과 폭풍 하늘/화산/설원 수정 사항은 보존해야 합니다.
