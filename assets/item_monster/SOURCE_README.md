# 헬리 트리오 - 아이템 몬스터 이미지 리소스

기존에 선택한 빨강·노랑 귀여운 아이템 헬기 디자인을 기준으로 정리했습니다.

## 파일 구성

- `frames/`: 프레임별 **실제 투명 PNG** 총 29장 (각 320×256 px)
- `item_monster_atlas.png`: 8열×5행으로 배치한 통합 스프라이트 아틀라스 (2560×1280 px)
- `idle_strip.png`: 대기/프로펠러 회전, 6프레임
- `move_strip.png`: 이동/도망, 6프레임
- `directions_strip.png`: 8방향 외형 참고
- `hit_strip.png`: 피격, 3프레임
- `explosion_strip.png`: 파괴, 4프레임
- `drop_strip.png`: 체력/무기 강화 아이템 2종
- `item_monster_large.png`: 기존 시안의 대형 캐릭터 PNG (투명 배경)
- `manifest.json`: 파일별 이름·프레임 시간·아틀라스 좌표
- `preview.html`: 브라우저에서 애니메이션 시험 가능

## 아틀라스 행 설명 (0부터 시작)

- 0행: 대기(0~5열)
- 1행: 이동(0~5열)
- 2행: 8방향(0~7열, 위에서 시작해 시계방향)
- 3행: 피격(0~2열), 파괴(3~6열)
- 4행: 드롭 아이템(체력 0열, 강화 1열)

아틀라스 각 칸 크기는 320×256이고, 몸체 중심은 대체로 (160,127)에 맞춰져 있습니다.
프레임 재생 속도는 `manifest.json`의 `duration_ms`를 참고하세요.

**참고:** 원본 콘셉트 이미지에서 투명도 정보를 활용해 요소별로 추출한 리소스이므로,
프레임 간 미세한 외형 차이·잔여 빛 번짐이 있을 수 있습니다. 실제 배포 전 게임 화면에서
축소 테스트를 권장합니다. 기존 게임 코드는 변경하지 않았습니다.
