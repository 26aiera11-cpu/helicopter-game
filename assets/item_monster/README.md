# 아이템 몬스터 독립 관리

작업 브랜치: `feature/independent-item-monsters`. 기존 시험 구현을 보완했으며 main/Pages에는 배포하지 않는다.

- `item_monster.js`가 별도 배열·등장 대기·타이머·이동·피격·그리기를 관리한다. 게임 본체의 최소 호출과 정적 스크립트 연결을 사용하며 전역 update/draw/warnEnemy를 재정의하지 않는다.
- HP 5, 발사/접촉 공격 없음, 랜덤 이동·접근 회피, 10초 수명이다. 기존 속도 45/53/61/69px/s를 넘지 않는다.
- 아이템몹 처치는 기존 점수 API로 +200점과 itemKills만 반영하며 일반 처치 목표는 증가시키지 않는다. 시간 만료는 무보상이다.
- 드롭은 기존 50:50 체력/강화, 효과 +2/+1, 16초 수명, 13px 반경과 단계 간 보존을 재사용한다. 최대 상태 보상 개선은 보류한다.
- 일반 단계/지역 전환은 살아 있는 개체의 위치/잔여 수명을 초기화하지 않는다. 기본 보스 정책은 등장 대기와 개체를 보상 없이 정리한다. 떨어진 아이템은 보존한다.
- 초기 시험 코드의 8초/7초/11~16초와 동시 1개를 확정값으로 쓰지 않는다. 호환 기본값은 기존 지역·단계별 간격과 22% 판정이며, 일반 몬스터의 기존 78% 출현 기회도 유지한다.
- `itemMonsters.configure({intervalSeconds, probability, maxActive, allowDuringBoss, stageRules})`로 독립 조정할 수 있다. 간격/정원 null은 기존 식을 상속한다. 새 주기·최종 정원은 아직 미확정이다. 혼잡 상황에서 이전 공유 정원과 정확히 같은 출현량을 보장하지 않는다.

## 제공 이미지

첨부 ZIP의 원본 29프레임, 2560×1280 아틀라스, manifest를 수정 없이 보존했다. 정적 임시 이미지 12개는 원본 프레임으로 교체했고 누락된 방향/피격/파괴 프레임도 포함했다. 원본 설명은 `SOURCE_README.md`다.

실행은 아틀라스 하나를 사용한다. 대기 6×115ms, 이동 6×105ms, 방향 8개, 피격 3×95ms, 파괴 4×95ms를 사용하며 셀 320×256 비율과 (160,127) 중심을 유지한다. 드롭 PNG 두 장은 보관만 하며 기존 아이템 UI는 바꾸지 않는다. 이미지 누락 시 대체 이미지를 생성하거나 그리지 않는다.

## 검증·남은 작업

실제 Chromium/오프라인 독립 HTML의 생성 분리·체력·무공격·회피·10초 퇴장·실탄/관통·드롭·점수·단계/보스·애니메이션·3개 가로 화면 검사와 기존 기능 회귀를 실행했다. 생성 주기 최종 승인, 실제 갤럭시 난이도/성능·센서·스피커·파일 실행은 남아 있다.
