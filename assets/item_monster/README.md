# 아이템 몬스터 독립 관리 (검토용 브랜치)

현재 아이템 몬스터는 일반 적 생성 파이프라인 밖에서 관리합니다. 기존 인라인 게임 본체(index.html)는 대용량 내장 이미지 때문에 수정하지 않고, `assets/score/score.js` 마지막에서 `assets/item_monster/item_monster.js`를 로드하는 호환 레이어 방식으로 연결했습니다. 이는 임시 통합 방식으로, 후속 코드 구조 정리 시 본체로 적절히 편입하는 것이 좋습니다.

## 동작
- 일반 적 생성에는 더 이상 아이템 몬스터의 22% 대체 확률을 적용하지 않습니다. 일반 몬스터 처치 조건은 기존 6마리입니다.
- 아이템 몬스터는 별도 타이머, 별도 경고 표시, 별도 배열과 이동·피격·퇴장·드롭 처리로 관리합니다.
- 임시 등장 설정: 새 플레이 후 8초, 단계 전환 후 7초, 이후 11~16초 간격(난수), 동시 1마리. 보스가 등장하거나 단계가 바뀌면 몬스터 자체는 정리합니다.
- 체력 5, 10초 후 퇴장, 사격 없음, 플레이어 접근 시 도망. 처치 시 체력/무기 강화 50:50 보상, 떨어진 아이템은 기존 16초 수명과 단계를 넘기는 보존 규칙을 따릅니다.
- 점수는 기존 로컬 점수 모듈 규칙 그대로: 일반 +100, 아이템 +200. 아이템 몬스터 처치로 일반 6마리 처치 목표는 진행되지 않습니다.
- 기존 트리오/빙글/탱코 공격 및 보스 처리는 보존하되, 빈 일반 표적 구간에서 빙글 유도탄이 아이템 몬스터를 겨냥할 수 있습니다.

## 이미지 상태 (미완료)
- `frames/idle_01.png`에는 승인된 빨강·노랑 헬기를 게임 크기용 투명 PNG로 축소한 이미지가 포함돼 있습니다.
- 현재 `idle_02~06.png` 및 `move_01~06.png`는 이미지 누락에 따른 깜박임을 방지하기 위해 **임시로 같은 PNG를 가리키는 정적 플레이스홀더**입니다. 실제 모션 이미지가 아닙니다.
- `hit_01~03.png`와 `explosion_01~04.png`는 아직 저장소에 업로드하지 않았고, 임시 효과 표시를 사용합니다.
- 사용자가 승인한 29프레임 ZIP에서 해당 PNG들을 `assets/item_monster/frames/` 경로에 넣어 플레이스홀더를 교체하면 코드가 자동으로 새 프레임을 사용합니다.
- 최종 이미지 크기/중심점/모션의 게임 내 시각 검증, 갤럭시 테스트는 아직 수행하지 않았습니다.

## 코드 및 검증
- 실행된 검증: JS 문법 컴파일, 모의 런타임에서 일반 경고가 항상 normal임, 독립 시간 생성, 체력 5 타격과 보상 1회, 일반 적 처치 카운트 불변, 보스 진입·단계 전환 시 정리.
- 미실행: 실제 브라우저 재생/비주얼·터치 테스트, 모든 29프레임 실제 등록, 전체 회귀검사.
- GitHub Pages의 `main`은 변경하지 않았고, 배포·병합하지 않았습니다.

## 후속 작업
1. 승인된 원본 PNG 프레임을 위 경로에 올리고 크기/중심점과 애니메이션의 실제 게임 검증
2. 일반 적/보스/총알/게임오버·점수·아이템 지속시간 회귀검사
3. 모듈이 기존 `update`, `draw`, `warnEnemy`를 감싸는 임시 통합을 제거하도록 게임 본체를 모듈화(별도 승인·검토 후)
4. 아이템 몬스터 등장 빈도·규칙은 게임 플레이를 확인하고 별도로 조정
