# 아이템 몬스터 — 지역별 처치 수 기반 등장

`feature/independent-item-monsters`에서 개발하며 main/Pages에는 승인 없이 반영하지 않는다.

- 본체 표시 80×64px, 충돌 반경20px. 기존64×51.2/r16에서1.25배이며 원본 이미지·중심·비율은 그대로다.
- 지역 진입 시1~4단계 중 서로 다른3개를 고르고, 선택 단계마다 일반 처치 기준1~4를 미리 정한다. 지역당3회는1차 시험 설정이다.
- 기준 처치 이벤트가 발생하면1.4초 예고를 즉시 예약한다. 예약 상태는 잠기므로 한 단계에서 다시 예약하지 않는다. 실제 등장 시 해당 기회를 사용한다.
- 시간/22% 반복 생성은 제거했다. index.html의 일반 몬스터용 기존78% 판정은 유지한다.
- 5단계에서 새로운 예약은 만들지 않는다. 이전 단계의 예약은 보스/지역 전환에도 완료하며, 살아 있는 개체도 남은 수명을 유지한다.
- HP5,10초 수명, 무공격·회피/이동 속도와 애니메이션은 그대로다. 놓치거나 만료돼도 같은 단계 기회를 다시 주지 않는다.
- 처치200점/itemKills만 반영하며 일반 처치 목표6과 생성 기준에는 포함하지 않는다. 기존50:50 체력/강화·효과+2/+1·16초 드롭 수명·지역/단계 보존을 재사용한다.
- 새 게임에서 계획·예약·개체를 초기화한다. 종료 확인과 게임 오버3초는 모두 정지한다.

설정: `itemMonsters.configure({opportunitiesPerRegion:3})`. 0~4를 허용하며 이미 선택한 지역 계획은 바꾸지 않고 다음 지역/새 게임부터 적용한다. 일반 게임은 실제 일반 처치 훅과 예약 완료로만 생성한다. `spawn(position)`은 기존 수동 검사 장면 호환용이며 보스 단계에서는 직접 호출도 거부한다.

첨부 원본29프레임·아틀라스·manifest·SOURCE_README.md는 수정하지 않는다. 대기6×115ms, 이동6×105ms, 방향8개, 피격3×95ms, 파괴4×95ms, 셀320×256/anchor(160,127)을 유지한다. 드롭PNG 두 장은 보관만 하며 기존 아이템UI는 유지한다.
