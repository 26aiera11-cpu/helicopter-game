# 월드 2 화산 그래픽 검토팩 v1

`feature/volcano-art-assets` / [Issue #14](https://github.com/26aiera11-cpu/helicopter-game/issues/14) / 2026-11-04 KST.

승인된 **신비로운 화산지대 B안·일반 몬스터 첫 애니메이션 시안·상향 날개 마그마 드래곤**을 참조해 만든 분리 리소스다. **새 PNG의 최종 외형 승인은 아직 받지 않았으며 게임에는 연결하지 않았다.** 기존 게임·월드·능력치·입력·사운드·배포 파일은 그대로다.

| 리소스 | 파일/프레임 |
| --- | --- |
| 배경 | `background/volcano_1920x864.png`, 정확히 1920×864 |
| 배경 생성 원본 | `background/volcano_generated_original.png`, 1870×841 |
| 불씨콩 | `monsters/ember_bean.png`, `animations/ember_bean_atlas.png` |
| 용암 도마뱀 | `monsters/lava_lizard.png`, `animations/lava_lizard_atlas.png` |
| 화산 박쥐 | `monsters/volcano_bat.png`, `animations/volcano_bat_atlas.png` |
| 마그마 갑충 | `monsters/magma_beetle.png`, `animations/magma_beetle_atlas.png` |
| 마그마 드래곤 | `monsters/magma_dragon.png`, `animations/magma_dragon_atlas.png` |

일반 4종은 각각 **대기1·이동4·공격1·피격2·소멸4 = 12프레임**, 보스는 **대기4·이동6·공격4·피격3·소멸4 = 21프레임**, 합계69프레임이다. 공격은 짧은 입/몸체 발광 포즈이며 탄환·공격 패턴은 만들지 않았다. 과도한 이펙트 대신 짧은 피격·소멸 표현을 사용한다.

일반 몬스터 모두 프로펠러가 없고, 얼굴은 이미지 아래를 향하는 탑다운 기준이다. 보스 머리는 아래, 꼬리와 날개 끝은 위를 향한다. 배경에는 글자·로고·패널·캐릭터·탄환이 없다. 가장자리 용암/결정과 어두운 중앙 전투 공간을 구성했다. **타일용이 아닌 단일 cover 배경**이며 반복 경계 처리나 장애물 판정은 포함하지 않는다.

## 프레임 사용 규약

`asset_manifest.json`의 `rect_px`를 반드시 사용한다. 생성 시트는 완전한 등간격 격자가 아니므로 `row*cell` 방식으로 잘라서는 안 된다. 아틀라스 PNG는 생성 결과 그대로 보존하고 JSON에서 개별 사각형과 기준점을 지정했다.

- `rect_px`: 원본 시트에서 읽을 정수 `x,y,width,height`.
- `source_size_px`: 모든 프레임에 공통인 가상 셀320×320.
- `sprite_source_rect_px`: 그 셀 안에서 그릴 위치/크기. 너비/높이를 그대로 사용하며 정사각형으로 강제 변형하지 않는다.
- 기준점은 가상 셀 중앙160,160이다. 시트 안에서 사용할 기준점도 `pivot_in_atlas_px`에 기록한다.
- `source_slot_px`와 행/열 경계는 저작 위치를 설명하는 메타데이터다. 실제 소비 좌표는 `rect_px`다.
- `base_content_bounds_px`는 좌상단/우하단 좌표, `rect_px`는 좌상단/너비/높이이므로 혼동하지 않는다.
- `frame_duration_ms`, `loop`는 아트 검토용 시간이다. 대기/이동만 반복이며 피격/공격/소멸은 일회성이다. 소멸 완료 후 표시 중지는 향후 게임 연결 작업에서 처리한다. 뷰어는 확인 편의를 위해 모든 상태를 반복한다.
- `preview_content_width_px`는 대비 샘플 크기일 뿐, 게임 표시 크기나 충돌 반경·전투 수치의 확정값이 아니다.

갑충은 생성 시트의 대기/이동 윤곽 중심이 가상 셀에서 가로20.5px·세로17.5px 범위로 흔들려, 프레임마다 윤곽 중점을 기준점으로 보정했다. PNG는 바꾸지 않았으며 보정 후 측정 중심은160,160으로 일치한다. 이는 윤곽 사각형의 중심 검증이며 얼굴/다리의 모든 점이 고정되거나 게임 충돌 중심을 확정했다는 뜻은 아니다.

예시(Canvas2D, 게임에 추가하지 않은 사용 설명):

```js
const [sx, sy, sw, sh] = frame.rect_px;
const [dx, dy, dw, dh] = frame.sprite_source_rect_px;
ctx.drawImage(atlas, sx, sy, sw, sh, dx, dy, dw, dh);
```

## 원본·투명도·한계

아트 제작/수정은 이미지 생성 도구로 수행했다. 기본PNG5개와 시트5개·배경 생성 원본은 도구 출력과 바이트가 같다. 배경만 종횡비를 보존해1921×864로 기계적으로 확대 후 중앙1열을 잘라 정확한1920×864로 내보냈다. 원본을 덮어쓰지 않았다. Python/Pillow는 픽셀·좌표·해시/CRC 검사에만 사용했다.

기본/시트는 모두 실제 RGBA다. 흰색/체크무늬가 구워진 배경이 아니다. 다만 생성 원본의 **알파1~7 미세 잔여 픽셀**은 보존돼 있고 명목상 빈 셀에도 일부 존재한다. 표시 윤곽/여백 측정 기준은 알파8 이상이다. 이 기준에서 모든69프레임은 비어 있지 않고 각 읽기 사각형에 최소8px 여백이 있으며, 누락/겹침/잘림이 없다. 알파를 후처리해 완전 정리했다고 주장하지 않는다. 밝은/어두운 배경의 실제 브라우저 검토에서는 사각형 배경/눈에 띄는 잔여 테두리를 발견하지 않았다.

시안의 픽셀을 그대로 분리한 파일이나 전용 손그림 연속 원화·8방향 시트는 아니다. 세부 선/포즈와 미세 정렬·실기기 가독성의 최종 승인, 필요 시 알파 완전 정리는 후속 검토 사항이다. 승인 전 게임 연결·화산 전투/지역 등록·배포는 진행하지 않는다.

원본 참조4개와 출처/해시/테스트/미리보기는 [검토 보고서](../../docs/review/volcano-art-assets/README.md), [매니페스트](asset_manifest.json)에 있다. 체크무늬와 헬기/탄환 샘플은 뷰어에만 있으며 배경PNG에 포함되지 않는다.
