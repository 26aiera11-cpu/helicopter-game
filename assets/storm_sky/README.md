# 폭풍 하늘 — Issue #26

월드 2 시험 전용 세 번째 지역입니다. 기본 월드 1에는 포함되지 않습니다.

- 전달된 `storm_sky_visual_assets.zip`의 배경과 네 일반 몬스터 PNG를 바이트 그대로 사용합니다.
- 보스 설명판 두 장은 `references/`에 보존했습니다. `storm_overlord.png`는 승인 참고 디자인의 캐릭터만 imagegen으로 투명 분리한 결과이며, 금색 번개 장식·구름·양쪽 터빈·수염·회오리 꼬리 디자인을 유지합니다. 설명판을 그대로 게임 스프라이트로 사용하지 않습니다.
- PNG 하나를 비손실 단일 셀 아틀라스로 사용합니다. 매니페스트의 개별 사각형·피벗과 5상태/16개 변환 키프레임(총80개)을 런타임이 적용합니다. 대기·이동·공격·피격·소멸은 확대/기울기/알파 기반이며 새로 그린 개별 포즈 애니메이션은 아닙니다.
- `config.js`의 일반 전투/혼합 확률/생성 간격·상한은 폭풍 하늘의 1차 시험값입니다. 다른 지역 설정을 참조하거나 덮어쓰지 않습니다. 일반 단계 목표는 기존6킬이며 정상5단계도6킬 후 보스, 개발자 직접5는 즉시 보스입니다.
- `spawns.js`는 독립 시드 PRNG입니다. `combat.js`는 네 일반 전투 역할, `boss_combat.js`는 세 무작위 일반 패턴과 체력50%에서 한 번만 발동하는 네 번째 각성 패턴을 담당합니다.
- 2페이즈 공격률은×1.2(시간÷1.2), 탄속×1.1입니다. 휴식은 최소1.5초입니다. 기존 보스 HP/강화 보정/보상/점수 경로는 유지합니다.
- 회오리는 피해 없이 안전한 위치로 옮기며1.4초 접촉 쿨다운과0.75초 보호를 사용합니다. 안전한 위치가 없으면 이동하지 않습니다. 회전은 표시 전용이므로 헬기의 조준 방향을 변경하지 않습니다.
- 전용 BGM은 후속 작업입니다. registry 음악 프로필0으로 기존 숲 일반/보스 곡을 명시적으로 임시 사용합니다. 기존 음악 파일·선택 BGM·화산 전용 곡은 수정하지 않습니다.
